# Choosr Brand Assets

- `choosr-app-icon.png`: 1024 × 1024 RGB master used for the iOS marketing icon
  and legacy launcher sizes.
- `choosr-adaptive-foreground.png`: transparent master for Android adaptive and
  monochrome icon layers.

The mark is a bold ink-navy **C** whose opening resolves into a check on a
signal-orange field. Keep the silhouette, colors, proportions, and clear space intact.
Do not add a heart, wordmark, border, or additional colors inside the launcher icon.

Platform exports are stored in the native iOS asset catalog and Android `mipmap-*`
resource folders. Regenerate exports from these masters rather than resizing an existing
small launcher file.
